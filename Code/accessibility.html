Accessibility

Accessibility Statement

JL Earthworks & Design LLC is committed to ensuring digital accessibility for people of all abilities.

Our Commitment

JL Earthworks & Design LLC strives to ensure that this website is accessible to people with disabilities. We are committed to making our digital presence usable by everyone, regardless of ability or device, and we continuously work to improve the user experience for all visitors.

Conformance Status

This website is designed and developed with reference to the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA, published by the World Wide Web Consortium (W3C). These guidelines explain how to make web content more accessible for people with disabilities and more user-friendly for everyone.

We aim to meet WCAG 2.1 Level AA conformance. Some content may not yet fully meet the standards; where we are aware of such gaps, we are working to address them.

Accessibility Features of This Site

  • Semantic HTML structure with proper heading hierarchy.
  • Descriptive alternative text on meaningful images.
  • Keyboard-navigable interface with visible focus indicators.
  • Skip-to-content link for screen reader and keyboard users.
  • Sufficient color contrast between text and background.
  • Form fields with associated labels and clearly indicated required fields.
  • Honor for the prefers-reduced-motion system setting.
  • Responsive layout that adapts to a variety of screen sizes and zoom levels.
  • Properly labeled icon-only buttons and links.

Known Limitations

While we work to ensure accessibility, some content may not yet be fully accessible. Specifically:

  • Some hero photographs are decorative and are marked accordingly. Functional photographs include descriptive alt text.
  • Third-party content (such as embedded fonts) is governed by third-party accessibility practices.
  • Older PDF documents linked from this site, if any, may not be fully tagged for screen readers; please contact us for an accessible version.

Feedback & Assistance

We welcome your feedback on the accessibility of this website. If you encounter accessibility barriers, need information in an alternative format, or need assistance using any part of this site, please contact us:

Assessment Approach

We assess the accessibility of this website using a combination of self-evaluation, automated testing tools, and manual review. We update content and code as needed based on findings and on user feedback.

Compatible Technologies

This website is designed to be compatible with the following assistive technologies:

  • Recent versions of major screen readers (NVDA, JAWS, VoiceOver, TalkBack).
  • Speech-recognition software (Dragon NaturallySpeaking, Voice Control).
  • Browser zoom up to 200% without loss of content or functionality.
  • Keyboard-only navigation.

Browsers & Devices

This website is designed to work with current versions of major browsers (Chrome, Firefox, Safari, Edge) on desktop and mobile devices. Older browsers may not display all features as intended.
